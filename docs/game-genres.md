# 游戏类型普查与识别策略映射

> 目的：为"用户自建游戏档案"提供类型预设（genre）基础。类型本身**只用于引导 ROI
> 校准与候选规则预设**，不代表系统对某款游戏已具备可靠的自动识别能力——
> 识别准确性仍然只能通过真实授权录像 + 人工标注评测验证（见 adapter-development.md）。

## 一、市面主流游戏类型全谱

综合 Steam / 主机与移动渠道分类及行业通用术语，玩家高频录制分享的对抗类游戏
主要集中在 1–5 类；其余类型收录以保证"所有类型可自建档案"。

## 二、类型 → 识别策略映射（通用 OCR 适配器的预设方向）

| 类型簇 | 主要事件类型 | 典型 ROI 位置（相对坐标经验区） | 候选规则预设方向 |
|---|---|---|---|
| MOBA | ELIMINATION_NOTICE、ROUND_END(推塔/大龙) | 播报横幅：上中 (x0.3,y0.05,w0.4,h0.1)；经济板：上侧 | 20s 窗口 ≥3 次击杀播报 → 团战 |
| FPS/TPS/大逃杀 | ELIMINATION_NOTICE、SCORE_CHANGE | Killfeed：右上 (x0.6,y0.02,w0.38,h0.25)；比分：上中 | 短窗密集 killfeed → 连杀 |
| 体育/卡牌/音游 | SCORE_CHANGE、ROUND_START/END | 比分牌：上中/上左 | 分数骤变 + 回合结束 |
| 格斗/动作 | ROUND_END、MANUAL_MARKER | 回合标记：屏幕上缘两侧 | 回合结束 + 手动补标高光 |
| 竞速 | SCORE_CHANGE(名次) | 名次板：左上/右上 | 名次跃升 |
| 沙盒/MMO/其它 | MANUAL_MARKER 为主 | 按游戏 HUD 校准 | 手动事件驱动 |

## 三、诚实性约束

1. 以上 ROI 区域是**校准起点**，不是"开箱即用"——不同分辨率、宽高比、HUD 缩放、
   语言都必须逐游戏重新校准，相对坐标缩放不代表自动支持所有布局。
2. 类型预设不改变识别引擎能力；generic-ocr 适配器保持 EXPERIMENTAL，
   未验证前任何游戏档案都不得宣称"支持自动识别"。
3. 不匹配时明确退回手动模式（引擎行为已有保证）。
